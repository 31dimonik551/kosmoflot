# KosmoFlot 🚀

3D-раннер от третьего лица (космическая тематика) для Android с мета-системами:
**Battle Pass**, **ежедневная награда за вход** и **награда за просмотр рекламы**.

Репозиторий содержит две реализации:

| Папка | Что это | Статус |
|-------|---------|--------|
| [`prototype-web/`](prototype-web) | Играбельный прототип на **Three.js** — запускается в браузере, проверен в headless-Chromium. Быстрая обкатка геймплея и мета-систем. | ✅ Готово, играбельно |
| [`unity/`](unity) | Полноценная **Unity + C#** версия под Android: скрипты геймплея и мета-систем + Editor-сборщик сцены. | ✅ Скрипты готовы, открывается в Unity 2022.3 LTS |

## Веб-прототип

```bash
cd prototype-web
python3 -m http.server 8123
# открыть http://localhost:8123
```

Ядро: авто-бег, 3 полосы, прыжок/подкат, процедурные препятствия и кристаллы,
нарастающая скорость, счёт, game over. Мета: Battle Pass (Free/Premium, XP за
забеги), ежедневная награда со стриком, удвоение добычи за «рекламу».
Сохранения — `localStorage`.

## Unity-версия

Открыть `unity/KosmoFlot` в Unity Hub → меню **KosmoFlot → Build Playable
Scene** → **Play**. Подробности, архитектура, интеграция Unity Ads и сборка
под Android — в [`unity/README.md`](unity/README.md).
